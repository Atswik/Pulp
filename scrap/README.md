# Archived experiment: correction helper

`CorrectionHelper/` contains the earlier Qwen-based visual correction experiment. The current app build and recognition workflow do not use it. Some dormant correction types and review code remain in the app source; restoring the experiment would require wiring its helper back into the app bundle and reviewing its behavior.

The private benchmark inputs, downloaded model, generated outputs, and build artifacts are not included. The model's download and use are not required for the current GLM-only pipeline.
